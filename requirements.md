# 📦 Requirements

This project requires the following Python libraries:

## 🔧 Core Dependencies

* numpy
* pandas
* matplotlib
* seaborn
* pygame

---

## ⚙️ Installation

You can install all dependencies using:

```bash
pip install numpy pandas matplotlib seaborn pygame
```

---

## 🐍 Python Version

* Python 3.8 or higher is recommended

---

## 💡 Notes

* Make sure `pygame` is installed properly, as it is used for visualization
* If using a virtual environment, activate it before installing dependencies

---

## 🚀 Run the Project

After installing dependencies:

```bash
python main.py
```
